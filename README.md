# My Nuvio — Build N1 (catalog-only addon)

**Published install URL:** https://titanlll.github.io/my-nuvio-n1/manifest.json

GitHub Pages serves the generated `site/` directory. The manifest lists only populated catalogs; all 58 catalog definitions remain in `catalogs.json`. Check the [live status](https://titanlll.github.io/my-nuvio-n1/status.json) for held feeds and their reasons.

## Build N1 contents

- All **58 approved catalog definitions** are preserved in `catalogs.json` and grouped by network/topic.
- **10 BetterPosters discovery rows** remain with the BetterPosters addon you already installed; publishing duplicate copies would clutter Nuvio.
- **3 personalized For You rows** remain with a separately connected personalization addon/account. This project does not access your viewing history.
- **12 genres and 8 moods** in `browsing-folders.json` generate **40 additional catalog rows**. Seven additional Shahid-homepage-inspired discovery rows are generated by `shahid_home_rows.py`. Folder navigation remains a Nuvio/collection-manager feature; these are catalog rows, not automatically installed folders.
- The generator publishes each **additional catalog only if it can produce justified, identifiable entries**. Held catalogs are explained in `status.json` after build, rather than filled with fabricated rankings or false subscription/subtitle claims.
- Uses **official Netflix Saudi weekly Top 10** from the published country dataset. In some cases Netflix title names cannot be matched unambiguously to IMDb IDs; those chart entries are skipped, and the original rank is preserved in the description. If the data is inaccessible, it is held, *not* replaced with a fake Top 10.
- Uses **TMDB** for clearly attributed movie/TV discovery and for correctly identified movie/series IDs. Some topic-based or release-date catalogs are necessarily *curated/approximate*, not original service lists.
- Curated source-verified awards and mature animation entries are seeded in `data/verified.json`. Three Shahid Saudi discovery rows now use TMDB/JustWatch provider availability; the separate *exclusives and originals* rows still require individual source verification. There is **no fabricated Shahid Top 10**.
- Source-backed starter entries include Rashash for Saudi Originals and Oppenheimer for Golden Globes & BAFTA. Two historically verified Turkish Netflix entries (The Protector and Last Call for Istanbul) remain in `data/verified.json` as evidence examples, but are **not** the source of the new live Turkish discovery rows. A separate playback addon must provide usable streams/subtitles in Nuvio.
- **Playback remains separate:** AIOStreams, Turkish streaming addons, subtitle addons and Nuvio itself handle streams, subtitles, Library and Continue Watching.

## Publish free with GitHub Pages

1. Create a **public** GitHub repository called `my-nuvio-n1`, using your own GitHub account.
2. Unzip this project. Upload **its contents**, not the `.zip` as one file, to the repository root, preserving `.github/workflows/deploy.yml`, `data/verified.json`, `catalogs.json`, and `generate.py`.
3. Get a free personal **TMDB API Read Access Token** via https://www.themoviedb.org/settings/api . Read TMDB's usage/attribution terms.
4. In GitHub: **Repository → Settings → Secrets and variables → Actions → New repository secret**. Name it `TMDB_BEARER_TOKEN` and paste the token. Do not put the token in any public file or send it in chat.
5. Under **Repository → Settings → Pages**, set the build source to **GitHub Actions**.
6. Under **Repository → Actions → Publish My Nuvio Build N1**, choose **Run workflow**. If GitHub requests that workflows be enabled, enable them for your own repository. The workflow also schedules a daily refresh.
7. Check that the workflow succeeds and that **Pages** provides a real website URL. The install address is your website URL followed by `/manifest.json` — generally `https://YOUR_USERNAME.github.io/my-nuvio-n1/manifest.json`, but use the URL GitHub actually assigns.
8. On the Sony TV: **Nuvio → Settings → Addons → Install / Add by URL**, then paste your *live* HTTPS `manifest.json` URL. If your version organizes those menus differently, use the addon URL entry screen.

**BetterPosters badges:** Your existing BetterPosters addon keeps its own badges and discovery lists. This project uses normal TMDB posters unless you set an optional secret `BETTERPOSTERS_POSTER_PATTERN` using the **actual URL pattern supplied by your BetterPosters configurator**, containing `{imdb_id}` or `{id}`. Do not guess an undocumented endpoint. Depending on Nuvio's metadata/poster priority, another installed addon may override these posters; this must be tested on the Sony TV.

## Files

- `catalogs.json` — all 58 frozen Build N1 catalog definitions, with mode and source choices.
- `browsing-folders.json` — the 20 approved genre/mood labels, organized under two folder concepts.
- `browse_catalogs.py` — generates the 40 movie/series browsing definitions without editing the original 58 catalogs.
- `shahid_home_rows.py` — generates six Saudi Shahid provider discovery rows inspired by identifiable Arabic homepage themes; does not scrape Shahid's personalized homepage.
- `data/verified.json` — curated, source-attributed IMDb examples and exclusivity claims; if adding a **subtitle-verified** item, record `origin_country: "TR"`, `original_language: "tr"`, `arabic_subtitles_verified: true`, and `subtitle_source_url`. Live Turkish *discovery* rows do not read this allowlist or promise subtitles. For Shahid exclusives, verify `original_language: "ar"` and `shahid_exclusive_verified: true` with a source.
- `generate.py` — static catalog builder using TMDB and the official Netflix TSV.
- `.github/workflows/deploy.yml` — daily automatic generation and GitHub Pages deployment.
- `tests/test_n1.py` — tests for manifest schema, 58-item plan and verification guards.
- `tests/test_browse_catalogs.py` — browsing coverage, movie/TV taxonomy, route and ordering tests.
- Generated public `status.json` — which catalogs are actively published and which were held, with reason.

## Testing locally

`python -m unittest discover -s tests -v`

Tests run offline using mocked source data and require no API credentials. Pull requests run tests only. Pushes to `main`, daily schedules and manual runs on `main` test, generate, and deploy. Build credentials are scoped to the generator step. Errors report exception classes and HTTP codes without request URLs or exception messages, which can contain API keys.

To verify the published manifest and every advertised catalog endpoint:

`python verify_site.py https://titanlll.github.io/my-nuvio-n1`

The deployment job also checks the URL returned by Pages against the version in the merged source. It retries briefly for propagation, so the previous cached version cannot count as a successful new deployment.

### Deployment diagnosis (2026-11-15)

The first two runs failed because no TMDB credential was configured. A later run generated and uploaded successfully, but `deploy-pages` found no artifact metadata immediately after upload. Run [43665862169](https://github.com/TITANlll/my-nuvio-n1/actions/runs/43665862169) succeeded after separating build and deployment and adding a delay. The workflow keeps separate jobs and now checks artifact visibility for up to 60 seconds instead of sleeping a fixed interval. It derives the build URL from Pages configuration and grants Pages write/OIDC permissions only to deployment. Artifacts have distinct build-attempt names; the build passes its actual artifact name to deployment, so a build retry cannot create ambiguous duplicate artifacts and a deployment-only retry still selects the correct build. If artifact visibility times out, retry the failed deployment job. A failure after deployment in the live verification step means Pages was published but the endpoint checks need investigation.

Review and merge the proposed changes to `main` to activate the updated workflow; review branches do not publish over the existing site.

To generate locally, set `TMDB_BEARER_TOKEN` and `PAGE_URL` to the actual public HTTPS base URL, then run `python generate.py`. The generator uses only the Python standard library. The official Netflix chart is a required source: if it cannot be downloaded, validated or mapped after retries, the build stops before replacing output, preserving the previous published website. Other unavailable catalogs remain held, not replaced with sample content.

### Genre and mood browsing (version 1.2.0)

The 12 genre labels and 8 mood labels each get separate movie and series rows, such as `Genre · Action · Movies`, `Genre · Action · Series`, and `Mood · Feel-Good · Movies`. They follow the original addon rows in the manifest. The 58 original definitions are preserved; `status.json` reports `original_planned: 58`, `browse_planned: 40`, `shahid_home_planned: 7`, `netflix_home_planned: 6`, and `planned: 111`. Only populated rows appear in the manifest.

Movies use TMDB movie genres. Series use TV genres, with exact keyword matches where a movie genre has no TV equivalent or TMDB combines two TV genres. If no matching keyword exists, the row stays held instead of becoming an unrelated general catalog. Moods use editorial genre, keyword, rating and runtime filters; they are subjective discovery lists, not age classifications or streaming-availability claims.

BetterPosters Discovery is first in `grouping-plan.json` and the complete saved plan. ### Netflix download recovery (version 1.2.1)

The official country TSV is about 32 MB. An interrupted transfer raises `http.client.IncompleteRead`, which is not an `OSError` and previously bypassed the retry loop. The downloader now retries the entire response, discards partial bytes, and gives this large source up to five attempts with a 120-second timeout per attempt. Normal API requests retain their existing timeout.

Before mapping titles, validate the required columns and the latest Saudi movie and TV charts, each with ten unique ranks from 1 through 10. At least one reliably mapped title is required in each feed. Original ranks and chart week remain in descriptions; ambiguous matches are skipped. Exhausted downloads, invalid charts or unmappable feeds stop publication instead of silently removing the Netflix rows. No request URLs or exception messages are logged.

### Shahid Saudi multi-poster discovery (version 1.2.2)

The Shahid rows had only one source-verified title (**Rashash**), so Nuvio displayed one repeated poster and made the catalog appear broken. Three Shahid row IDs now use the TMDB watch-provider registry to find **Shahid VIP** titles listed as available in **Saudi Arabia** via JustWatch data, with poster and IMDb mapping. The rows provide **Popular Series**, **Popular Movies**, and **Recently Produced Series**, up to 15 unique mapped titles each. Rows with fewer than five reliable title IDs remain unpublished.

Popularity ordering comes from **TMDB**, not Shahid's internal views. “Recently produced” means first air date, not “newly added to Shahid.” The addon does not claim real-time Shahid Top 10 rankings, exclusivity, playback availability, or Arabic subtitles. Provider catalogs and source-backed exclusive catalogs have separate verification rules; the latter are hidden until at least five independently documented titles are available. The release-date cutoffs are calculated on each build, not hardcoded.

If TMDB does not list Shahid VIP for a given media type or fewer than five valid items are found, the row is held with an explicit reason in `status.json`. GitHub preserves the last published site if the refresh raises an upstream error. The external SC+ addon remains separate.

### Arabic-style Shahid artwork (version 1.2.3)

The three Saudi Shahid provider-discovery rows prefer a **TMDB poster explicitly tagged Arabic** for each identified movie/series, when available. Poster selection uses TMDB's documented `/{movie|tv}/{id}/images` endpoint, and chooses the best-rated Arabic artwork that has a normal image path. If no Arabic artwork is available, or its optional request fails, the existing TMDB poster remains in place. This preserves the original 15-title target and avoids missing catalog rows.

**Important:** These are TMDB-hosted localized posters, **not Shahid's official proprietary marketing images**. Shahid's site serves its own artwork, but this project does not scrape, duplicate or republish its protected image feed. Nuvio controls how the poster rows are actually positioned and rendered. A separate metadata/poster addon such as BetterPosters may still take display precedence depending on the TV client's addon order. Streaming availability and subtitles remain separate from catalog artwork.

### Shahid homepage-inspired discovery rows (version 1.3.0)

Six extra Shahid discovery rows were added: Arabic drama, Egyptian series, Turkish movies, Syrian classics (series first aired by the end of 2016), Saudi series and Arabic comedy. They appear near the existing Shahid popular/recent sections, using TMDB/JustWatch's *Shahid VIP in Saudi Arabia* watch-provider filter, not Shahid's logged-in homepage or recommendation engine. **This is a structural approximation, not an exact mirror.** Shahid's Arabic homepage is personalized and changeable. Its internal “most watched,” Top 10, actual add-to-service date, search rankings, channel schedule and editorial promotions are **not** known from TMDB. The new Shahid rows are sorted by TMDB popularity under stated filters, not by Shahid's own viewing statistics. The Syrian “classics” date is an editorial boundary, not an official Shahid collection. Titles can vary as TMDB/JustWatch updates provider coverage, and posters prefer TMDB Arabic artwork where available. No private or account-specific Shahid URL or artwork feed is copied into this public repository.

`status.json` separates 58 original catalog definitions, 40 genre/mood rows and six Shahid-inspired rows (`planned: 104`). Only successfully populated rows are included in the public manifest.

### Shahid availability coverage (version 1.3.1)

Shahid Saudi provider-discovery rows now use TMDB's supported watch monetization categories `flatrate|free|ads` with the existing Saudi (`SA`) provider filter, instead of subscription-only `flatrate`. The pipe means **OR** in TMDB discover. This may include more titles indexed as free/ad-supported in addition to Shahid VIP, without adding extra rows or any paid API. Coverage is still limited by the provider records that TMDB/JustWatch exposes. This does **not** make Shahid VIP content free or establish access rights; free availability and subscription requirements must be checked on Shahid itself. Rankings remain TMDB popularity, not Shahid's official Top 10. FlixPatrol has not been integrated and requires no subscription.

### Turkish multi-poster discovery (version 1.4.0)

Eleven original Turkish catalog IDs are preserved for existing Nuvio installs, but their former single-title `verified` feeds are now real TMDB `discover` feeds. Categories include popular Turkish movies and series, comedy films, drama and crime series, top-rated movies (at least 30 TMDB votes), movies/series first released in the previous two years, Turkish TV shows with episode air dates in the previous 14 days, and Turkish-language movies and series listed on Netflix in Saudi Arabia by TMDB/JustWatch. Every discovery row filters original language `tr`, excludes adult catalog content, and checks the release/premiere cutoff against the current build date.

Popularity and average review scores are **TMDB metrics, not official Turkish network ratings**. The recent-episodes row uses TMDB episode broadcast dates, not proof an episode is available to stream. Original release dates do not mean the title was newly added to Netflix. Netflix Saudi availability is sourced from TMDB/JustWatch region/provider metadata and can lag the actual service. Arabic subtitle selection remains a feature of the playback/subtitle provider; the discovery rows neither check nor guarantee Arabic subtitles, so they can show many more relevant posters.

Each row requests up to six pages of TMDB candidates, deduplicates IMDb IDs and displays up to 15 distinct titles. When a feed has fewer than five reliably mapped titles, its row is held rather than showing one poster. The existing personalized SC+ Turkish addon remains separate and is not copied into the public repository. Historical subtitle evidence in `data/verified.json` remains for documentation and future explicitly verified features; it no longer controls Turkish discovery.

### Netflix Saudi: fuller discovery and chart matching (version 1.5.0)

These are **not Netflix's internal daily Top 10, exclusive originals, or newly-added-to-service dates**.

The separate two official Saudi Top 10 rows still use Netflix's weekly publicly published country TSV and preserve original chart positions. **Artwork:** The generator composes an original 500×750 JPEG poster using the source TMDB artwork with a dark rating badge (clearly marked **TMDB**, never IMDb), a **NETFLIX SA** regional catalog tag, a movie/series and year tag, and a ranking number **only** for titles verified against Netflix's official Saudi weekly Top 10. **Updating Nuvio:** GitHub Pages refreshes the addon in place at the same \`manifest.json\` URL after a successful main-branch deployment. The repository collection JSON files are configuration references, *not remote control of an installed Sony TV*: adding the nine new rows to a previously imported Netflix collection may require updating or reimporting the collection in Nuvio, depending on the installed version.
